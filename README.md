# VIVISECTED BRAIN!

This is a personal knowledge archive and desktop application designed to document the interests, experiences, discoveries, and curiosities that shape an individual.

From favorite movies and video games to cryptids, prehistoric creatures, scientific discoveries, and personal interests. This project aims to provide a centralized place to preserve an evolving collection of knowledge.

## PROJECT VISION

The goal is to develop a personalized desktop application that functions as a digital representation of an individual's interes and experiences.

This application will encourage connections between different subjects, allowing entries to become part of a larger personal knowledge archive.

## PLANNED FEATURES

Personal Archive: Store and organize personal interests, hobbies, and experiences.
Media Collection: Catalog movies, television, video games, and books.
Creature Archive: Document cryptids, prehistoric life, and unusual organisms
Research Journal: Record observations, discoveries, research, and personal notes.
Categorization: Organize entries using categories, tags, and searchable metadata.
Personal Ratings: Rate and review collected media and experiences.
Knowledge Connections: Establish relationships between different entries and subjects.
Local Database: Persist information locally on the user's computer.

## TECHNOLOGY STACK

C# : Primary programming language
.NET : Application development platform
Avalonia UI : Cross-platform desktop interface
SQLite : Local relational database
Git : Versional control
GitHub : Repository hosting and project management

## Getting Started

### Prerequisites

1. macOS, Windows, or another supported platform
2. .NET SDK
3. Visual Studio Code or another compatible IDE
4. Git

### Running the Current Project

Clone the repository:

```bash
git clone https://github.com/brainlesscpu/VivisectedBrain.git
```

Navigate into the project directory:

```bash
cd VivisectedBrain
```

Run the current C# project:

```bash
dotnet run
```
